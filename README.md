# Сообщения / Повідомлення

Веб-приложение (PWA) с готовыми сообщениями на разные темы. Сообщение можно скопировать,
отправить в Telegram / WhatsApp / Viber (или любое другое приложение через системное меню «Поделиться»)
и добавить в избранное ♡.

- Выбор: **короткие** или **длинные** сообщения → **категория** → список сообщений
- Поиск по сообщениям в категории и в избранном
- Избранное хранится на устройстве пользователя (без регистрации)
- Интерфейс на русском и украинском (переключатель RU/UK в шапке)
- Светлая и тёмная тема (по настройкам системы)
- Работает офлайн и устанавливается на телефон как приложение

Без фреймворков и сборки: чистые HTML, CSS и JavaScript.

## Структура

```
index.html               главная страница
css/style.css            стили
js/app.js                логика приложения
js/i18n.js               тексты интерфейса (ru, uk)
sw.js                    service worker (офлайн-режим)
manifest.webmanifest     описание PWA
icons/                   иконки
data/index.json          список категорий
data/short/*.json        короткие сообщения по категориям
data/long/*.json         длинные сообщения по категориям
tools/validate.mjs       проверка данных
tools/add-category.mjs   импорт категории из .txt
.github/workflows/       автопроверка и публикация на GitHub Pages
```

## Формат данных

`data/index.json` — список категорий для каждого раздела:

```json
{
  "short": [
    { "id": "category_1", "title": { "ru": "Категория 1", "uk": "Категорія 1" }, "icon": "💬", "file": "short/category_1.json" }
  ],
  "long": [ ... ]
}
```

Файл категории:

```json
{
  "messages": [
    { "id": "1", "text": "Текст сообщения" },
    { "id": "2", "text": "Можно с переносами строк.\n\nВторой абзац." }
  ]
}
```

- `id` категории — латиница, цифры, `_` или `-`.
- `id` сообщения должен быть уникальным внутри категории и **не меняться** — к нему привязано избранное.
- Порядок категорий и сообщений в приложении = порядок в файлах.
- `text` может быть и объектом с переводами: `{ "ru": "…", "uk": "…" }` — тогда текст показывается на выбранном языке.

### Импорт из текстового файла

```bash
node tools/add-category.mjs short category_3 messages.txt "Категория 3" "Категорія 3" 🌸
```

В `.txt` сообщения разделяются строкой `---` (или пустой строкой, если `---` в файле нет).
Скрипт создаст `data/short/category_3.json` и добавит категорию в `data/index.json`.

Проверка данных:

```bash
node tools/validate.mjs
```

## Запуск локально

Нужен любой локальный веб-сервер (из-за загрузки JSON открыть `index.html` двойным кликом нельзя):

```bash
python3 -m http.server 8000
# или: npx serve .
```

Откройте http://localhost:8000

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и отправьте туда проект:
   ```bash
   git init
   git add .
   git commit -m "Первая версия"
   git branch -M main
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После каждого `push` в `main` данные проверяются и сайт публикуется по адресу
   `https://<логин>.github.io/<репозиторий>/`.

## Обновление

- Новые сообщения появляются у пользователей сразу (данные загружаются из сети, офлайн — из кэша).
- При изменении интерфейса (`css`, `js`, `index.html`) увеличьте `VERSION` в `sw.js`, чтобы обновить кэш.
